# Nexora Technology Stack

## Backend

- Framework: Laravel 13.17
- PHP requirement: 8.3+
- Authentication: Laravel Sanctum bearer tokens

## Database

- Provider: Supabase
- Engine: PostgreSQL

## Frontend

- Framework: React 19.2
- Language: TypeScript
- Build tool: Vite 8
- API client: Axios

## Mobile

- Framework: Expo 57 / React Native 0.86

## Important Environment Variables

- `VITE_API_URL`
- `DB_CONNECTION`
- `DB_HOST`
- `DB_PORT`
- `DB_DATABASE`
- `DB_USERNAME`
- `DB_PASSWORD`
- `APP_URL`
- `CORS_ALLOWED_ORIGINS`

No secrets are recorded in this vault.
